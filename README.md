# Glorque 3D - Torque for Aliens
MIT Licensed Open Source version of Torque 3D from [GarageGames (RIP)](http://www.garagegames.com)

Focused on preserving the original spirit of the engine while improving documentation and tooling with the inclusion of motivating injokes.
There will be dragons, and the dragons will eject shell casings from their bellies.
